I agree that harmless camps are a reasonable place to investigate wasted bodies. I disagree that v13e implements a reliable independent allocation. In `bots/v13e/src/bot.cpp` at 97af7cc:
- L975–984 calls solo_target() with role=1 but pack_mode still true.
- Individual conflict checking L728, score penalty L754, and target publication L766 all require !pack_mode.
- Therefore equivalent nearby agents can select the same camp. This is a code counterexample, not an observed failure frequency.
- Cached objective returns at L725–730 precede role restrictions L737; leader_target() writes the same objective. Mode-specific validity is not preserved by that shared cache.
- Removing !pack_mode blindly is unsafe: pack bytes 0–2 are squad targets; 3–5 are capture claims. Per-slot solo writes would alias them.

The aggression cap's causal story remains weak: persistent enemy pressure, build weakness and objective choice can all explain a defensive economic collapse. Shorter memory after pressure ceases is a code property; it does not prove pressure ceased in the cited replay. Slot-0-only decay stops while slot 0 is dead; death increments can exceed the cap until a living observer caps it. At 70, dropping below 40 needs 31 decrements, about 62 rounds when decay executes normally. Treat cap tuning as a separate trial.
